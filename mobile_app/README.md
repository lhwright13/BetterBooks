# Mobile App
This directory contains the Flutter application. To get started:

1. Run `flutter create .` to generate project files.
2. Replace `lib/main.dart` with the provided stub if needed.

### API configuration
Create `lib/api_config.dart` and define your API base URL:

```dart
const String apiBaseUrl = 'http://localhost:8000';
```

Update the value to match your backend deployment.
